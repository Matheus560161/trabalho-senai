*Como funciona...*

Quando abrir o menu aparecera 5 opcoes:
1 - Cadastrar equipe:onde é possivel cadastrar as equipes de esport e futsal ultilizando um nome e logo após escolher a modalidade
2 - Consultar equipes: onde é possivel ver as equipes cadastradas nas competicoes 
3 - Cadastrar partida: onde é possivel cadastrar as partidas, primeiro selecione a modalidade após isso as equipes que irao disputar a partida e por fim selecione o placar desejado 
4 - Ver historico: serve para ver o historico de partidas jogadas e cadastradas anteriormente na opcao 3 
5 - para fechar nosso sistema

*Funções POO...*

*Abstração:* serve para deixar as classes mais simples, mostrando apenas as informações importantes para o funcionamento do sistema.

*Encapsulamento:* serve para proteger os dados das equipes e partidas, evitando que sejam alterados de qualquer maneira.

*Herança:* permite que as classes Futsal e Esport aproveitem características que já existem na classe Time, evitando repetir código.

*Interfaces:* servem para definir algumas regras que as classes precisam seguir, como acontece com iTime e IPartida.

*Polimorfismo:* permite que uma mesma função tenha comportamentos diferentes. Por exemplo, o método jogar() pode funcionar de uma forma para Futsal e de outra para eSports.
